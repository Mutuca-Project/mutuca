# Mutuca

**Uma plataforma de dados aberta para jornalismo investigativo e pesquisa cívica.**

O Mutuca nasceu de uma pergunta simples: como garantir que uma informação pública — um contrato, uma licitação, um dado orçamentário — possa ser verificada mesmo depois que o portal governamental que a publicou sair do ar ou alterar o conteúdo?

A resposta é uma plataforma de dados construída sobre três princípios:

- **Auditabilidade:** cada dado coletado tem uma origem rastreável e um histórico preservado.
- **Reprodutibilidade:** qualquer pessoa pode replicar uma investigação do zero, em qualquer computador.
- **Transparência metodológica:** a lógica de análise é legível, versionada e aberta à revisão.

Esta documentação explica os conceitos por trás da plataforma, as decisões de design que a moldam e a arquitetura que a sustenta. Não é necessário ter experiência em engenharia de dados para acompanhar — o texto foi escrito para jornalistas, pesquisadores e qualquer pessoa interessada em como dados públicos podem ser trabalhados com rigor.
